# Rebalance Key Crafting

Chest keys are single-use — one key, one locked chest — so opening a run of
vaults quietly eats your bars. This drops the crafting cost to **a quarter** of
vanilla, never below 1 of each ingredient.

The keys themselves are untouched: same keys, same chests, same loot. Only the
recipe is cheaper, and the workbench shows the reduced cost, which is exactly
what gets consumed — no gap between what you see and what you pay.

Covers all seven tier keys: Copper, Iron, Scarlet, Octarine, Galaxite,
Solarite, Relucite.

## Settings

**Options → Mod settings** — cost (1 ingot, ¼, ½ or vanilla), whether it applies
to tier keys only or every craftable key, and an on/off switch. Changes need a
restart; the menu offers to do it for you.

## Requirements

**Mod Settings Menu** and **CoreLib** — mod.io offers to install both when you
subscribe.

## Multiplayer

Install on both the client and the server.
